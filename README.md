# Linux Security & Data Auditor

## Overview
Automated Bash-based auditing toolkit designed to evaluate Linux system security posture, verify critical file permissions, and inspect user access policies in cloud and enterprise environments.

## Project Roadmap & Capabilities
- [ ] **Phase 1: File & Permission Audit** (Identify insecure `chmod` configurations).
- [ ] **Phase 2: Privilege Escalation Review** (Scan `sudoers` and active user groups).
- [ ] **Phase 3: Log Analysis & Monitoring** (Inspect system authentication logs).
